# UI-UX-Experiment4

## Aim:
To design a low-fidelity wireframe diagram for a generic mobile application/website using
Balsamiq, covering the five essential screens of a typical app — Welcome/Splash Screen,
Login/Signup Screen, Home/Dashboard Screen, Content/Product Listing Screen, and
Checkout/Contact/Final Action Screen — focusing on layout structure, navigation flow, and
placement of UI elements without using colour or detailed graphics.

## Algorithm:
1. Identify the purpose of the generic application and list the core user journey from app
   launch to task completion.
2. Open Balsamiq and create a new wireframe project for the application.
3. Design the **Welcome/Splash Screen** — app logo, app name, tagline, and a primary
   "Get Started" call-to-action leading into the auth flow.
4. Design the **Login/Signup Screen** — tab switcher for Login/Sign Up, email and password
   fields, a primary action button, and secondary links (forgot password, social login).
5. Design the **Home/Dashboard Screen** — top navigation bar (logo, search, profile), a
   banner/promo area, category selector, featured-items section, and a bottom navigation bar.
6. Design the **Content/Product Listing Screen** — header with back action and filter, search
   bar, filter chips, and a grid of content/product cards (image, title, price placeholders).
7. Design the **Checkout/Contact/Final Action Screen** — order summary, shipping/contact
   details form, payment method selection, total, and a final "Place Order" action button.
8. Connect all screens with directional links to represent the navigation flow: Splash →
   Login/Signup → Home → Listing → Checkout.
9. Review each screen for clear placement, spacing, and hierarchy, using only greyscale boxes,
   lines, and placeholder text (no colour, no detailed graphics).
10. Export the wireframes and push the project to this repository.

## Output:
Five wireframe screens were produced:
1. Welcome / Splash Screen
2. Login / Signup Screen
3. Home / Dashboard Screen
4. Content / Product Listing Screen
5. Checkout / Contact / Final Action Screen

See `wireframes.pdf` (or the `/wireframes` folder) in this repository for the full set, and
`Lab_Report_Unit4_Wireframe.pdf` for the complete lab report.

**Navigation flow:** Splash Screen → Login/Signup Screen → Home/Dashboard Screen →
Content/Product Listing Screen → Checkout/Final Action Screen. The bottom navigation bar on
the Home and Listing screens also allows lateral movement between main sections (Home, Search,
Cart, Profile).

## Result:
A complete low-fidelity wireframe diagram for a generic application was successfully designed
in Balsamiq, covering all five required screens. The wireframes clearly establish the layout
structure, element placement, and end-to-end navigation flow of the application without
relying on colour or high-fidelity graphics, fulfilling the objective of the experiment.
